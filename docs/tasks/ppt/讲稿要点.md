# CarbonLife 碳足迹 · 答辩讲稿要点

> 配套 `CarbonLife-答辩PPT.pptx`（15 页，16:9），建议讲解 5–8 分钟。每页 1–3 句口头词。
> 各页的讲稿也已写入 PPT 的「备注」（演讲者视图可见）。
> 版本：2026-10-21 修订（新增碳小树 / 碳账单，口径对齐 README 与当前构建）。

1. **封面**：各位评委好，我们的作品是 CarbonLife 碳足迹，一款基于 HarmonyOS 的低碳生活记录与激励应用。
2. **痛点与选题**：在「双碳」目标背景下，日常低碳行为普遍「难记录、没反馈、难坚持」；同时用户对生活数据隐私有顾虑。这决定了我们坚持「数据默认留在本机，云备份由用户自主开关」。
3. **我们做了什么**：我们做了一件事——记录低碳行为，自动算出减排量与碳积分，再用激励和家庭共享让它可持续。
4. **目标用户**：面向关注环保与健康的家庭用户、学生与通勤上班族，以及希望与家人共同参与的用户。
5. **功能总览**：共 10 大功能：低碳行为记录、端侧 AI 识图、数据看板与导入导出、积分与荣誉、家庭碳积分、每日提醒、双碳科普、深浅主题，以及这轮新增的碳小树与碳账单；数据还支持本地整包备份与可选的云备份。
6. **亮点 1 · 13 种行为**：出行、节能、回收、餐饮四大类共 13 种行为，按「活动量 × 排放因子」自动估算减排量与积分。
7. **亮点 2 · 端侧 AI 识图**：用户选一张照片，设备侧识别物体并推荐对应的低碳行为，图片不出本机。
8. **亮点 3 · 数据看板**：提供日 / 周 / 月 / 年趋势，折线、柱状、饼图多种呈现；支持 CSV / JSON 导入与导出，导入时逐字段校验归一化，坏数据不会污染本机记录；碳账单还可以导出成 PNG 分享图。
9. **亮点 4 · 家庭碳积分**：生成或加入家庭码后，可在同一华为账号的多设备间同步，并按成员展示家庭减排与积分。
10. **亮点 5 · 积分 · 荣誉 · 树苗**：碳积分可兑换权益、解锁徽章与植树证书；这轮新增的碳小树由真实记录派生成长值（每日上限 80 点防刷、连续记录每天 +5%、断签不掉级，六阶段长成），下方这张碳账单把阶段、累计减排、积分 / 种树 / 活跃天数与减排构成汇成一页，可复制文案或保存成图片分享。
11. **设计与体验**：整体采用可跟随系统的浅 / 深双主题，颜色与控件统一走设计规范；关键动效支持「减弱动效」开关。
12. **技术底座**：基于 HarmonyOS / OpenHarmony 原生开发，使用 ArkTS 与 ArkUI 声明式 UI，Stage 模型、SDK 26.0.0；本机存储、端侧 AI、分布式数据、后台提醒，以及可开关的 AGC 云备份。
13. **隐私与安全**：记录默认只存本机，云备份是可选开关、默认关闭；家庭数据只在同一账号设备间同步，不经过第三方；识图在本机完成。
14. **验证与质量**：项目采用「写审分离 + 设备验证」，在模拟器上逐条核对验收清单；记录刷新、图表刷新、家庭聚合（本地侧）与碳小树 / 碳账单已复测通过，外壳冒烟 20/20 只覆盖导航与布局；还有四项待真机或待复测——分布式权限弹窗、跨设备家庭聚合、云备份端到端（BLOCKED）、导入运行时。
15. **展望与致谢**：后续计划对接真实碳普惠平台、完成云备份冲突合并与签名构建验证、接入系统无障碍与补齐平板多列布局。谢谢观看。
