## 六、改稿怎么改

PPT 是脚本生成的，改文字有两个办法：

- **直接改 PPTX**：文字都是原生文本框，双击就能编辑，字体统一微软雅黑。
- **改脚本重跑**：文案集中在 `_build_ppt.py` 的各 `pNN_xxx` 函数里，改完执行

  ```
  "C:/Users/1/AppData/Local/Programs/Python/Python310/python.exe" _build_ppt.py
  ```

  再用 `_preview_ppt.py` 出一遍预览图检查排版。

第二种适合大改（换页、调结构、统一改配色），第一种适合改几个字。

**注意**：页码是自动算的（`foot()` 里的 `CUR` 计数器 + `TOTAL = 22`）。加页删页时只要改 `BUILDERS` 列表和 `TOTAL`，页码和「xx / 22」会自己跟上，别手写页码。

## 七、还没统一的一件事：配色

设计文档第 5 章写死了答辩材料的三个值：

| | 设计文档声明 | 当前 PPT 实际 |
|---|---|---|
| 底色 | 暖白 `#F5F7F5` | `#F5FAF7`（肉眼无差） |
| 主色 | 墨绿 `#16210F` | `#1F5C3D`（更亮的绿） |
| 强调色 | **暖琥珀** | 绿 `#2E7D5B` / 薄荷 `#7FD6A4` |

三处里，底色和主色几乎看不出差别，**真正的冲突只有强调色**：文档说用暖琥珀，PPT 通篇是绿的。

两条路，成本都很低（配色是 6 个常量，改完重跑即可）：

- **方案 A（最小改动）**：保留绿色系，把强调色换成暖琥珀，底色换成 `#F5F7F5`。文档三句声明全部成立，PPT 不动结构。
- **方案 B（完全对齐）**：主色改 `#16210F`，整稿从「绿色系」变「墨黑 + 琥珀」编辑风。
- **方案 C（改文档）**：把文档里的「暖琥珀」改成「品牌绿强调」，PPT 不动。

我倾向 **A**：绿色是低碳的通用语义，全换成墨黑会丢掉这层暗示；而加一点琥珀做强调，反而让关键数字在投影上更跳。
