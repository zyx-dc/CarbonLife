# CarbonLife 演示视频 · 分镜

- 成片：`CarbonLife-演示视频.mp4` — 1920×1080 / **60fps** / H.264+AAC 48kHz / **49.6 秒** / 12.4 MB
- 配乐：原创合成 120 BPM（`tools/video/gen_music.py`），无旁白
- 工程：`tools/video/remotion/`（Remotion，React + CSS 逐帧渲染）
- 画面：全部为设备真实截图，非重绘件

## 一、版本迭代与两次纠错

| 版本 | 做法 | 结论 |
|---|---|---|
| v1 重绘版 | 米色背景上重画的界面片段 | 不是 App，撑不住"运行可用"，作废 |
| v2 keynote 慢版 | 纯黑底 + 手机居中 + 长镜头 | 画面是真的，但节奏闷、且运镜抖 |
| v3 节奏混剪 | 浅底/暗场交替 + 拍点硬切 | 节奏对了，但**音轨是静音**、数据与 PPT 不符 |
| **v4（当前）** | v3 + 配乐 + 重拍素材 + 对比度修正 | 见下 |

三处关键修正：

1. **抖动**。v2 用 ffmpeg `zoompan` 推近，每帧位移不足一像素，坐标取整后就是"一格一格"。v4 全部运镜走浏览器 CSS transform，亚像素合成；60fps 下相邻帧差异稳定 1.7–1.9%，无重复帧。
2. **静音**。v3 的 AAC 轨道是数字静音（−91 dB）。v4 用 numpy 合成 120 BPM 配乐，与剪辑拍点同源；母带 −16 LUFS / −1.5 dBTP。
3. **白卡放白底**。v3 浅底 `#F3F3F5` 上放白色界面，整帧只有 σ≈11 的对比，发灰。v4 把浅底压到 `#E9E9EC`，白色界面统一挪到暗场。

## 三、语法

| 手法 | 做法 |
|---|---|
| 拍点 | 120 BPM，一拍 0.5 秒；每条 3–8 拍，全硬切 |
| 景别 | 靠"整机在画面里变大"制造推近（800 → 880），不用裁切放大 |
| 明暗 | 白色界面一律暗场；浅色只给文字卡，明暗交替即节奏 |
| 排版 | 屏上字一行、23px、落在 `0.945H`（字幕位）；文字卡才放大 |
| 动效 | 文字卡"上移 20px + 淡入 + 0.985→1"，缓动只用减速 `cubic-bezier(0.16,1,0.3,1)` |
| 交互 | 两处**点击指示环**（选类别 / 拍照选图），青柠扩散两轮 |
| 重音 | 全片只有一处青柠大字：`0.17` |

**素材约束**：截图 1320×2232。铺满 1920 要放大 ≥1.45 倍，正文小字会虚。所以特写只给大数字与图表，其余用整机（降采样，最锐）。

## 五、素材与复现

截图取自模拟器 `Mate 90 Pro`（HarmonyOS 7.0 / API 26），原生 1320×2232：

| 文件 | 状态 |
|---|---|
| `01-home.png` | 0.17 / 47 / 3.57 / 270 / 连续 6 天 |
| `02-record.png` | 记录页（含 AI 识图入口、四类、行为、数量、保存） |
| `03-home-lower.png` | 今日任务（2/4 完成）+ 家庭碳积分 + 每日提醒 |
| `04-rewards.png` | 积分与荣誉（387 分） |
| `05-knowledge.png` | 科普专栏 + 自测 |
| `06..08-dash-*.png` | 看板 日 / 周 / 月 |
| `09-report.png` | 碳账单（3.57 kg / 387 分） |

```powershell
# 1) 导入种子并补一条今天的 1km 步行（成品状态 0.17/47/3.57/270/6天）
#    种子：scripts\make-demo-seed.ps1 -Push，App 内 看板 → 清空 → 导入

# 2) 抓图到 %TEMP%\ff\，再拷进工程
cd tools\video\remotion
Copy-Item "$env:TEMP\ff\*.png" public\shots\
Copy-Item "C:\Windows\Fonts\NotoSansSC-VF.ttf" public\fonts\

# 3) 出片
npm install
npx remotion render src/index.ts CarbonLife out/CarbonLife-v4.mp4

# 4) 配乐 + 混流（母带 −16 LUFS）
cd ..
python gen_music.py 52 bed.wav
ffmpeg -i remotion\out\CarbonLife-v4.mp4 -i bed.wav -filter_complex `
  "[1:a]atrim=0:49.557,afade=t=in:st=0:d=0.6,afade=t=out:st=47.2:d=2.3,`
   loudnorm=I=-16:TP=-1.5:LRA=11,aresample=48000[a]" `
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 48000 -movflags +faststart final.mp4
```

改分镜只动 `src/shots.ts`：`close`（裁切特写）/ `phone`（整机，可带点击环）/ `card`（文字卡），时长 `beats × 0.5s`。

## 六、已知边界

- **不是录屏**。这台模拟器无窗口运行、系统不提供 `screenrecord`，逐帧截图仅 ~3 fps，拿不到连续操作画面。"它真的能跑"只能靠现场演示证明；视频里的点击环是指示，不是录制。
- 特写受源图分辨率限制，只给大数字与图表。
- 累计记录条数（21 条）与 PPT 个别页（4 条）仍不同源，如需彻底一致需重拍 PPT 截图。
