> 版本：2026-11-05　|　目标时长 **3:40**（官方上限 5 分钟）
> 形态：全 App 实机录屏 + 后期真人旁白
> 设备：手机 `EMA-AL00U`（1280×2800）+ 平板 `LRT-W30`（家庭段双机）

## 一、录制前筹备（务必先做完，否则要重录）

## 二、录法

设备端**没有** `screenrecord` 命令（已实测 `/system/bin` 只有 `snapshot_display` 和 `uitest`），所以只能：

1. **主用：DevEco Studio 设备镜像 + OBS**
   - DevEco 打开「设备镜像」，OBS 采集窗口，1080p / 30fps / CQP 20
   - 好处：PC 上能实时看到画面、可加画中画、可边录边看时长
2. **备用：系统录屏**
   - 控制中心下拉 → 屏幕录制，1080p，开麦克风
   - 最稳，但每段要手动起停

**操作由脚本驱动**：`scripts/demo-drive.ps1` 用 `uitest uiInput` 注入点击，节奏固定、无手指遮挡、可无限次重录。先按脚本跑一遍确认路径，再开录。

> 录制注意：`rewards` 与 `know` 的滑到底需要 3 次 `swipe`，脚本里已包含；如果现场网络或渲染变慢导致少滑一次，最后一张卡会被 Tab 栏切掉，务必回看确认。

## 四、双机段怎么拍（第 08 镜）

这是全片最能打的一段，也最容易拍砸。

**拍法**：两台设备并排固定在支架上（或平放桌面俯拍），同时系统录屏，各自出一条 1080p 素材，后期左右并排。

**动作时序**（关键是让"变化"发生在镜头里）：

| 时刻 | 左（手机，正在操作） | 右（平板，被动） |
|---|---|---|
| 0s | 首页下滑到家庭卡片 | 首页下滑到家庭卡片 |
| 4s | 停留，让观众看清 4.83 / 578 / 2 人 | 同左，数字一致 |
| 8s | 返回首页顶部 → 记一笔骑行 5 km | 保持家庭卡片不动 |
| 20s | 回到家庭卡片，家庭减排由 4.83 变 5.68 | 数字同步跳变（约 300ms–1s 后） |
| 26s | 停留 3 秒，让两边差异可见 | 同左 |

> 注意：同步是**双向**的，如果右边先收到会先跳。剪辑时以先变的一侧为切点，或者把两侧画面错开 0.5 秒对齐，观感更好。

**风险**：两台设备的系统时钟、录屏起始帧不同步。建议开录后先各自静止 3 秒再开始操作，方便后期对齐。

## 五、后期要点

- 旁白真人录制，建议 48kHz / 24bit，安静房间，离麦 15cm，语速比平时慢 10%
- 字幕：按最终旁白出，不要沿用旧片的 55 条（时间轴已变）
- 转场：全部硬切，不做过场特效，产品演示越干净越好
- 真机素材统一：裁掉状态栏（顶部约 90px）、圆角遮罩、投影，放进 16:9 画布留白
- 调色：录屏素材本身偏冷，整体轻微提亮 + 降饱和 5%，与后期图形卡统一
- 导出：H.264 / 1920×1080 / 30fps / 8–12 Mbps / AAC 192kbps，总体 ≤100 MB

## 六、脚本

`scripts/demo-drive.ps1` 用法：

```powershell
# 先跑一遍看路径对不对（不录）
.\scripts\demo-drive.ps1 -Scene record -DryRun

# 正式录：一个人按录屏，另一个人执行
.\scripts\demo-drive.ps1 -Scene record
```

场景：`home-full` `home-top` `record` `vision` `dashboard` `rewards` `know` `family` `family-exit` `bill`

脚本只负责点击，**不负责录屏**——录屏请用系统录屏或 OBS，开始录之后再执行脚本。
