## 一、5 分钟演示路径

| # | 操作 | 预期 |
|---|---|---|
| 1 | 启动 App | 启动页 → 首页；顶部显示今日减排 / 积分 / 累计 / 种树 |
| 2 | 首页「碳小树」卡片 | 显示树形、阶段胶囊（含 `›`）、成长值、进度条、连续天数、今日成长 |
| 3 | 点「去记录低碳行为」→ 选「步行替代驾车」→ 保存 | 返回首页，**今日减排/积分/成长值同时增长**；任务「绿色出行」「坚持记录」自动打勾 |

| 8 | 「复制文案」 | 弹出「已复制」并关闭，粘贴可见完整文案（含树阶段与连续天数） |
| 9 | 「保存图片」 | 系统文件选择器，文件名 `carbonlife-report-<时间戳>.png`；确认后 Toast「碳账单图片已保存」；**打开图片应为不透明底**（深色模式下导出的暗色卡片同样可读） |
| 10 | 切「看板」 | 折线/柱状/饼图随周期切换；导出 CSV/JSON 正常 |
| 11 | 切「积分」「科普」 | 列表正常渲染，无空白 |
| 12 | 系统切深色模式 | 全站跟随（首页/看板/碳账单/树形均可读） |

## 三、设计要点（可讲）

- **成长值完全由记录派生**，没有可写状态 → 无法点按钮刷；
- **每日上限 80**，约 6~8 条记录封顶；连续记录 +5%/天（封顶 +50%）；
- **断签不掉级**，只影响当天加成；
- 阶段阈值 `0 / 60 / 180 / 420 / 900 / 2400`；
- 行为结构决定树冠装饰（出行→新叶 / 餐饮→果实 / 节能→花朵 / 回收→青环）。
